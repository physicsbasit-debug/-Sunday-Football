# Sunday Football

تطبيق عربي مخصص للهاتف لإدارة مجموعة كرة القدم الأسبوعية.

## النسخة الحالية
- قاعدة اللاعبين مع التقييم السري والمراكز.
- لصق أسماء الحاضرين وتسجيل الغياب تلقائيًا.
- دورة عالمية من 5 أيام.
- 1 ر.ع لكل حضور، مع رصيد مُرحّل وإعفاءات داخلية.
- جدول حضور ودفع بالرموز ⭕ / ✅ / ❌.
- توزيع أولي متوازن للفريقين حسب التقييم والمراكز.
- البيانات محفوظة محليًا في متصفح الجهاز في هذه المرحلة.

## قادم
- تبديل اللاعبين يدويًا بين الفريقين.
- إخراج صورة تشكيل احترافية لواتساب.
- تحسين تخصيص الحراس والمراكز.
- سجل دورات ومدفوعات أكثر تفصيلًا ونسخ احتياطي للبيانات.
